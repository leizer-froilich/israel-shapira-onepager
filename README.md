# ישראל שפירא · וואן פייג'ר

אתר תדמית בעמוד אחד לישראל שפירא, מדריך טיולים ומשפיען טבע ותיירות בציבור החרדי.

## מבנה
- `index.html` · תצוגה מקדימה מלאה (HTML/CSS/JS). פותחים דרך שרת מקומי, למשל `python -m http.server`.
- `lovable/IsraelShapiraLanding.tsx` · אותו עמוד כקומפוננטת React ללאבבל.
- `lovable/israel-shapira.css` · העיצוב לקומפוננטה.
- `lovable/public/` · פונטים, תמונות וסרטונים להעלאה ל-`public/` בפרויקט.
- `assets/` · תמונות (Magnific, ברישיון) וסרטוני הלקוח.
- `fonts/` · almoni + almoni-tzar (רישיון AlefAlefAlef).

## לפני עלייה לאוויר
- להחליף את מספר הטלפון הזמני (`972000000000` / `050-000-0000`).
- לאשר שעות פעילות.
- לחבר את הטופס לשליחה בפועל.
